O problema

Vistoria de ruas no RJ atende três famílias de equipamento com checklists diferentes — e o termo formal precisa sair em PDF.

Antes

Checklist única, sem termo

Uma vistoria de ruas legada (138 perguntas) servia para tudo, sem distinção de abrigo, relógio ou totem — e sem geração do Termo de Arrolamento em PDF.

Depois

Checklist sob medida + PDF

O checklist se monta conforme o equipamento e o painel (estático/digital), persiste respostas e fotos, e gera o PDF do termo com modelo do abrigo e mapa de satélite.

O que entrega

5 peças fechando o vertical slice.

Applicability

Matriz por estabelecimento: abrigo 497, relógios 449/466, totens 445/463. Painel por natureza do equipamento — relógios e totens não dependem de flag para ter painel.

Checklist dinâmica

Seções A/B/C com visibilidade por estabelecimento e por painel. Opção "Não se Aplica" para itens sem aplicabilidade no ponto.

Readiness

Gate do relatório: respostas aplicáveis, 6 fotos baseline, fotos NC e storage — o botão só habilita quando o termo está completo.

Snapshot + PDF

Snapshot → fila reports → TermoArrolamentoPdfJob → PDF no disk public, com modelo do abrigo e mapa de satélite.

UI no chamado

Checklist renderizado na Minha Rota + botão Gerar/Baixar no card do ticket.

Catálogo = dado, não código

Checklist, perguntas e report type entram por rollout manual (roteiro + planilha executados pelo William em produção). Zero maquinário de registro automático.

Mapa de satélite no PDF

Sem biblioteca npm — chamada server-side no worker, com fallback honesto.

ArcGIS World Imagery

TermoArrolamentoPdfJob::generateMap() chama o endpoint de export do World Imagery via Laravel HTTP (timeout 30s, bbox ±0.0025/±0.0012, 900×380), valida bytes com getimagesizefromstring e põe o pin vermelho via GD. Cache por report.

Fallback honesto

Sem coordenadas, provider fora ou bytes inválidos → SVG placeholder aprovado com as coordenadas como texto. Nunca um mapa quebrado.

Pendência de decisão — licença Esri

O endpoint público do ArcGIS é gratuito para uso não comercial, mas uso produtivo/comercial exige contrato com a Esri (ArcGIS Online, Enterprise ou credits). Decisão fica com o William: contratar Esri, migrar para Google Static Maps (com key) / OSM, ou manter o placeholder. Enquanto isso, o código já suporta a cadeia completa.
